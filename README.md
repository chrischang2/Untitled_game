# Willow Lake 🎣

A cozy low-poly fishing game made in Unity 6 (URP). You fish off a little dock with your friend **Mei**, and you talk to her with your real voice. She answers out loud.

Everything runs locally on your PC:

```
  hold V, speak ──► whisper.cpp (speech → text) ──► llama.cpp + Qwen3.5 (Mei thinks, streamed)
                                                        │ sentence by sentence
  Mei talks ◄── Piper TTS (text → speech) ◄────────────┘
```

Mei also notices what's happening around her. She comments on your catches, the sunset, and the rain, and she sometimes starts a chat on her own. The whole project uses only free (CC0 / OFL / MIT / Apache) assets. See [CREDITS.md](CREDITS.md).

## Quick start

1. **On a fresh clone, run the bootstrap once** (about 10 minutes, needs Unity 6000.0.68f1 from Unity Hub):
   ```powershell
   powershell -ExecutionPolicy Bypass -File Tools/bootstrap.ps1
   ```
   The repo only contains code and settings; the big binaries are gitignored and re-created by this script:
   - `Tools/fetch-assets.ps1` downloads the free models, audio and fonts into `Assets/ThirdParty/` (about 65 MB).
   - `Tools/setup-local-ai.ps1` downloads llama.cpp, the Qwen3.5-2B model, whisper.cpp, Piper and its voices into `LocalAI/` (about 1.7 GB). Add `-SkipAI` to the bootstrap to skip this.
   - Unity runs headless to set up URP and TextMeshPro and to generate the textures, materials, meshes and the `WillowLake` scene.
2. **Open the project** in Unity **6000.0.68f1**. Open `Assets/Scenes/WillowLake.unity` and press **Play**.
   The AI servers start automatically; the HUD dots in the top right turn green when Mei is ready (about 5–10 s).
   In the editor they keep running between Play sessions and close when Unity closes.
3. Or play the standalone build: `Builds/WillowLake/WillowLake.exe`. To make a new build, use the menu **Untitled Game → Build Windows Player**.

## Controls
| | |
|---|---|
| **WASD** / **Shift** | walk / jog |
| **Right mouse drag**, **scroll** | look around, zoom |
| **Hold left mouse**, release | charge and cast (aim with the camera) |
| **Click** when the bobber dives | hook the fish |
| **Hold left mouse** | reel in. **Let go when the fish pulls**, or the line snaps |
| **E** or move | reel your line back in |
| **Hold V** | talk to Mei (push-to-talk). Or switch Esc → **Talking → Hands-free (beta)** and just speak; Mei stops listening while she's talking, so headphones aren't required |
| **T** / **Enter** | type to Mei instead |
| **J** / **Tab** | fishing journal (19 catches, each with its Chinese name) |
| **C** | chat log |
| **H** | hide the HUD |
| **Esc** | menu: volumes, Mei's voice, talking speed, chattiness, language, day length |

## Tuning the AI (`LocalAI/localai.json`)
Any field of `Assets/Scripts/GenAI/LocalAIConfig.cs` can be overridden here. Some useful ones:
```json
{
  "llmModel": "models/Qwen3.5-2B-Q4_K_M.gguf",
  "whisperModel": "models/ggml-base.bin",
  "voice": "voices/en_US-kristin-medium.onnx",
  "llmThreads": 4,
  "externalLlmUrl": "",
  "externalLlmModel": ""
}
```
- **A smarter but slower Mei:** run `Tools/setup-local-ai.ps1 -ModelSize 4B` and point `llmModel` at `models/Qwen3.5-4B-Q4_K_M.gguf`. On this laptop's 4 GB RTX 3050, 2B replies in about 0.5 s and 4B takes a few seconds, because it only partly fits on the GPU.
- **Better speech recognition, for Chinese later:** run `Tools/setup-local-ai.ps1 -WhisperModel small-q5_1` and update `whisperModel`.
- **Use Ollama or LM Studio instead:** set `externalLlmUrl` (e.g. `http://localhost:11434/v1`) and `externalLlmModel`. The client speaks the OpenAI-compatible API.
- Measured on this machine (Ryzen 7 7435HS + RTX 3050 4 GB), game running at 144 fps: Whisper about 1.1–1.3 s, and about 2–3 s from releasing V to hearing Mei's first sentence.

## Troubleshooting
- **Mei doesn't hear me:** Windows Settings → Privacy → Microphone → allow desktop apps. The game uses the default recording device.
- **The status dots stay grey or red:** read `LocalAI/logs/*.log`. Make sure nothing else is using ports 8765 (LLM) or 8766 (Whisper).
- **Mei ignores something she should know:** the 2B model is small. Try the 4B model, or edit the persona in `Assets/Scripts/Companion/CompanionPersona.cs`.
- Progress is saved to `%USERPROFILE%\AppData\LocalLow\Cozy Local Games\Willow Lake\willowlake_save.json`.

## How it's built
Everything visual is **generated by editor scripts**, so the world can be rebuilt at any time:

| Menu (Untitled Game → …) | Batch equivalent (`Tools/unity-batch.sh <method>`) |
|---|---|
| Setup → Configure Project (URP, TextMeshPro, player settings) | `UntitledGame.EditorTools.ProjectSetup.Run` |
| Build Willow Lake Scene (terrain, lake, dock, cabin, forest, characters, systems) | `UntitledGame.EditorTools.SceneBuilder.Build` |
| Capture Preview Screenshots → `Captures/` | `UntitledGame.EditorTools.CaptureTools.CaptureAll` |
| Build Windows Player | `UntitledGame.EditorTools.BuildTools.BuildWindows` (or `RebuildAll`) |

**End-to-end self-test.** `Builds/WillowLake/WillowLake.exe -selftest` boots the AI and waits for Mei's greeting. It then speaks a question to her (Piper → Whisper → LLM → Piper), plays a fishing round, and takes screenshots. The report goes to `Captures/selftest/`. Add `-mandarin` to test the bilingual mode. The self-test uses its own save file.

```
Assets/
  Scripts/
    GenAI/        LocalAIServices (launches/monitors servers), OpenAIStreamingClient (SSE streaming),
                  WhisperClient, PiperTTS (persistent process), MicRecorder, SpeechText (sentence splitting)
    Companion/    CompanionBrain (conversation + autonomous remarks), CompanionPersona (prompt),
                  CompanionVoice (sentence-by-sentence TTS playback), CompanionController (follow/sit/head-bob),
                  VoiceChatController (push-to-talk)
    Fishing/      FishingController (cast → bite → tension minigame), FishingRod, FishDatabase, CatchJournal
    Environment/  WorldShape (lake maths), DayNightCycle, Weather, WaterRipples, Effects, …
    UI/           GameUI (HUD, bubbles, meters), Panels (journal, settings, chat log, catch card)
    Core/         SaveSystem, AudioManager, InputGate, GameBootstrap, SelfTest
    Progression/  ChinesePhrase + PhraseUnlockSystem (hooks for the language-learning phase)
  Shaders/        Comfy/Lit, Comfy/Water, Comfy/Sky, Comfy/Fish, Comfy/Particle (URP HLSL)
  Editor/         SceneBuilder, ComfyAssets, KenneyMaterials, ProjectSetup, CaptureTools, BuildTools
  ThirdParty/     Kenney models, CC0 audio, OFL fonts
```

## Toward Chinese learning
Settings → **Language → Mandarin practice (beta)** already does the following:
- Mei weaves one Mandarin phrase into each reply, e.g. 钓鱼 (diào yú), and invites you to repeat it.
- Whisper switches to auto language detection.
- Chinese text is voiced by the Mandarin Piper voice, while English stays in Mei's English voice.
- Every fish has hanzi and pinyin in the journal and on its catch card.

The roadmap is in [docs/companion-genai-plan.md](docs/companion-genai-plan.md).
